# IPIPTEST

A 20-item Free Vision personality questionnaire built with Free Pascal for
16-bit real-mode DOS. The program is an informal self-reflection tool, not a
clinical instrument. See `files/README.TXT` for the DOS-facing instructions.

`make build` compiles the executable, and `make image` creates a 1.44 MiB
FAT12 disk. Its keyboard-driven workflow should be checked through DOSBox
Automation when it changes.
