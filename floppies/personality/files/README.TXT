IPIPTEST - DOS PERSONALITY TEST
==============================

IPIPTEST.EXE is a short, 20-item questionnaire based on public-domain IPIP
item wording. It gives a simple Big Five profile: Openness, Conscientiousness,
Extraversion, Agreeableness, and Emotional Stability.

TO TAKE THE TEST
----------------
1. Start the computer with this floppy in drive A:, or run IPIPTEST.EXE.
2. When prompted, press Enter to start the test.
3. For each statement, select 1 through 5:
     1 Strongly disagree
     2 Disagree
     3 Neither agree nor disagree
     4 Agree
     5 Strongly agree
4. Press the number for your answer. It is selected and the test immediately
   advances to the next statement. Enter does not select an answer. F10 opens
   the menu; F2 starts another test.
5. Your scores are shown when all questions are complete. Scores run from
   0 to 100; a higher score means more of that trait.

IMPORTANT
---------
This is an informal self-reflection exercise, not a clinical instrument.
It does not diagnose personality, mental health, or any other condition.
Do not use the result for medical, employment, education, or legal decisions.
Answers are only kept in memory and are not written to disk.

SYSTEM
------
IBM PC-compatible 8086 or later, DOS, and a color or monochrome text display.
The program is compiled for 16-bit DOS real mode with Free Pascal and
FreeVision using the small memory model.
