# Rebel Floppy

Packages Rebel 3.x, a customizable spreadsheet for IBM PC-compatible systems
with at least 384 KiB RAM and DOS 2.1. Its upstream README permits use,
copying, and distribution without a license or registration fee.

The disk includes its full documentation, sample worksheets, and standard
script library. `INSTALL.BAT` copies them to `C:\APPS\REBEL` and creates
`C:\SYSTEM\REBEL.BAT`.
