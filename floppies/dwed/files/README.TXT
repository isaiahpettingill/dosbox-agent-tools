DWED
====

DWED is a real-mode 8086 text editor and IDE.

Run DWED.EXE from this disk. DWEDOVL.EXE and DWED.CFG must remain in the same
directory as DWED.EXE.

The editor supports F1 for built-in help, syntax highlighting, multiple files,
and mouse input when a DOS mouse driver is available.
