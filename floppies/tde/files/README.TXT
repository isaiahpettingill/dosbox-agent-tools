TDE 5.1v - THOMSON-DAVIS EDITOR
================================

This disk contains TDER.EXE, the 16-bit DOS edition of TDE 5.1v.

TO START
--------
At the DOS prompt, type:

  TDER

To edit a file directly, type:

  TDER FILE.TXT

TDE loads TDE.CFG, TDE.HLP, and TDE.SHL from this same directory. Keep these
files together with TDER.EXE. F1 opens TDE help, F2 saves, and F3 quits.

The upstream distribution README is included as TDEINFO.TXT.
