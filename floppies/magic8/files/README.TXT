THE COSMIC EIGHT BALL

Think of a yes-or-no question, then type twelve random keys to shake the
oracle. The more absurd your shaking, the more impressive the magic looks.

After the answer appears, press Enter to ask again or Q to quit. Extra shake
keys are discarded before the answer can accept a response.

Run INSTALL to copy the disk to C:\APPS\MAGIC8 and add MAGIC8 to C:\SYSTEM.
