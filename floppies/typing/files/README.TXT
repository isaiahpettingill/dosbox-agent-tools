TYPE FURY - A PUBLIC-DOMAIN TYPING GAME
========================================

TYPEFURY.EXE gives you five sentences from old books. Type each sentence
exactly as printed, including capital letters and punctuation. Wrong keys add
to the mistake counter; Backspace removes your most recently accepted key.
When the five rounds end, the game reports your words per minute and accuracy.

TO PLAY
-------
1. Start the computer with this floppy in drive A:, or run TYPEFURY.EXE.
2. Press any key at the title screen.
3. Type the displayed sentence exactly. Press Esc to leave the game early.
4. Press any key after the final score to return to DOS.

SOURCES
-------
The prompt pool consists of short excerpts from the following public-domain
works: Thomas Hobbes's Leviathan (1651); Edgar Allan Poe's The Raven and
Annabel Lee; the anonymous Cantar de mio Cid; Jonathan Swift's Polite
Conversation and A Modest Proposal; William Shakespeare's Hamlet and Richard
III; Arthur Conan Doyle's The Hound of the Baskervilles; and Lewis Carroll's
Alice's Adventures in Wonderland.

SYSTEM
------
IBM PC-compatible 8086 or later, DOS, and a text display. TYPE FURY is an
Open Watcom C program compiled as a 16-bit DOS real-mode application using the
small memory model.
