# PC Word Floppy

Packages freeware PC Word 1.90 and its printer drivers, manuals, project
files, HyperRead helper, and RSort utility. Upstream metadata specifies DOS
2.11, 320 KiB RAM, 560 KiB disk space, and an 8088 PC/XT.

`INSTALL.BAT` retains the program's required `PCWORD\DRIVERS` and
`PCWORD\MANUALS` directories under `C:\APPS\PCWORD`, then creates `PCWORD.BAT`
and `RSORT.BAT` in `C:\SYSTEM`.
