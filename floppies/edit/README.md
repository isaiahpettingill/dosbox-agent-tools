# FreeDOS EDIT

This floppy packages the pinned upstream FreeDOS EDIT 0.9b release binary and
help file, the complete supplied Borland C source/build files, and the
GPL-2.0-or-later `LICENSE`. It intentionally adds no compiler or C-- build
dependency.

`make image` creates a 1.44 MiB FAT12 image. `EDIT.EXE` and `EDIT.HLP` must
remain together at the DOS root.
