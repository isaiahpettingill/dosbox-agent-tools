GW-BASIC FOR MS-DOS

This disk contains a rebuilt 1983 GW-BASIC interpreter and an experimental
GWBASICA variant. Run GWBASIC for the normal interpreter or GWBASICA for the
variant with a few later BASIC conveniences.

Run INSTALL to copy the disk to your hard drive. See HELP.TXT for a short
command reference and ORIGIN.TXT in the installed directory for provenance.
