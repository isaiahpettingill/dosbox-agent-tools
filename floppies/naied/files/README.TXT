NAIED - DOS TEXT EDITOR
=======================

NAIED is a small MIT-licensed DOS real-mode text editor by Kagamma.

TO START
--------
At the DOS prompt, type:

  NAIED

To edit or create a file, type:

  NAIED FILE.TXT

KEYS
----
Ctrl-S saves. Ctrl-O opens or creates a file. Ctrl-F searches. Ctrl-R
replaces. Ctrl-G goes to a line. Esc quits the editor.

NAIED.LIC contains the MIT license and NAIED.TXT contains upstream notes.
