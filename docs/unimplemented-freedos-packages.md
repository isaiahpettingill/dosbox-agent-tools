# Unimplemented FreeDOS Packages

These packages were reviewed from
[`clasqm/freedos-repo`](https://github.com/clasqm/freedos-repo) but are not
packaged here. The mirror's statement that an unlicensed program is treated as
public domain is not a redistribution license.

| Package | Reason |
| --- | --- |
| `belief` | Its package metadata says no distinct licensing information was found and only treats it as public domain. |
| `elements` | Contains only an executable and descriptive metadata; no license or redistribution grant. |
| `skyglobe` | Documentation contains no redistribution grant. |
| `life2` | Includes credited BASIC source without a license or redistribution grant. |
| `nero5` | Includes usage text but no license or permission. |
| `visicalc` | Retains Software Arts copyright notice without a redistribution grant. |
| `timebox` | Identifies the author as unknown and supplies no license. |
| `aida` | Metadata and notes supply no license or redistribution terms. |
| `vtprolog` | Documentation mentions source availability but supplies no source or license terms. |

Paid/shareware packages and packages requiring processors newer than an NEC V20
are excluded rather than cataloged here.
